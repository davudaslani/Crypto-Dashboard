# CryptoSignal Pro

Live Krypto-Dashboard mit KI-Marktanalyse.

## Features
- Live-Preise via CoinGecko API
- Fear & Greed Index
- BTC Preis-Chart (14 Tage)
- Markt-Dominanz Donut-Chart
- KI Trading Signal (Claude by Anthropic)
- Wochentag-Heatmap: Beste/schlechteste Handelstage
- Key Support & Resistance Levels
- Scrollender Live-Ticker

## Starten
Datei `index.html` im Browser öffnen. Fertig — kein Server nötig.

## Daten-Quellen
- Preise: [CoinGecko](https://coingecko.com) (kostenlos)
- Sentiment: [Alternative.me](https://alternative.me/crypto/fear-and-greed-index/)
- KI-Analyse: [Anthropic Claude](https://anthropic.com)
